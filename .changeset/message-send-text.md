`operator message send` takes `--key <message> --text <text>` in place of a JSON file, and `operator question answer` takes `--text <answer>` in place of `--file`, so a SuperAgent steers and answers without writing a file first.
`--file` keeps working for both, and the `super-agent` skill shows the short form.
