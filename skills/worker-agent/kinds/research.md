# Research

Use `research` for the brief's question, not a wider investigation.
Store its artifact in the assignment's reports directory outside the checkout; list its absolute path under Supporting files.
Submit the Markdown report with `operator report submit --file <report.md>`.
For promotion, read [handoff](../../handoff/SKILL.md) by path and list its document in the report's Supporting files.
Keep the note in assignment device-state files, not OS temporary storage.
Keep it within about 60 lines.
Acceptance belongs to your SuperAgent; a returned report follows the result's next step.
