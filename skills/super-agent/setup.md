# Setup

Register explicitly with `operator project register` from the main checkout.
Confirm commands with `operator --help`; report missing capabilities rather than inventing them.
Use `operator ready` before dispatch; resolve blockers and inspect warnings.
Readiness checks static prerequisites, not live host capability.

Release selection and publication need the person's authority.
Install only the selected release's skills and hooks with `operator install --opencode --claude`.
Use `operator herdr install` for its plugin.
Preserve modified skills, consumer-owned links, read-only settings, and unmatched plugins for their owner.
Inspect interrupted installs before retrying.
Preserve databases and verified backups on corruption; never repair real legacy state.
