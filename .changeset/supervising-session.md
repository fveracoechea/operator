One agent session supervises a source. A wait or a dispatch records the caller's session beside its Herdr pane, another session's coordination commands for that source refuse with `source_supervised_elsewhere`, and `operator source take-over --person-instructed` moves supervision on the person's instruction. The turn-end guard now speaks only to the supervising session, so a new session in the same pane gets no reminder.
