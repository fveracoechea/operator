# Slack

Slack messages, thread replies, and quick check-ins with teammates.
The reader sees the message between other work and gives it a few seconds.

## Tone and length

- Write relaxed and friendly. A greeting, contractions, and "thanks" are fine.
- Put the point or the request in the first sentence.
- Keep a check-in to one to three sentences. Keep a status update to a few bullets.
- Ask one clear question when you need an answer, and name who must answer it.
- Reply in the thread of the message you answer.

STE rules still apply. A short message has whole sentences with articles and verbs.
"PR up, pls review" becomes "My PR for the date parser is ready. Can you review it today?"

## Format

- Slack uses its own markup. Bold is `*text*` with one asterisk, and a link is `<url|label>`.
- Use bullets for two or more updates or items. Use bold for the one item that needs action.
- Use no headings. A message that needs headings belongs in a document or a canvas, with a link in Slack.
- Give a link a short label that says what it is.

## Before you post

Show the person a draft before you post a message in their voice.
